# Wireframes

Exporte os 4 frames do Figma como PNG e coloque aqui com estes nomes exatos,
para que apareçam automaticamente no README principal:

- sobre-mim.png
- projetos.png
- experiencias.png
- contato.png

Como exportar no Figma: selecione o frame > painel direito, seção "Export" >
escolha PNG > clique em "Export [nome do frame]".
